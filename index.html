Dasar-Dasar Excel

Kenali medan tempur: apa itu sel, range, dan bagaimana Excel "berpikir".

Istilah wajib

IstilahArti
WorkbookSatu file Excel utuh (.xlsx)
Worksheet / SheetLembar kerja di dalam workbook (tab di bawah)
KolomVertikal, ditandai huruf: A, B, C, …
BarisHorizontal, ditandai angka: 1, 2, 3, …
Sel (Cell)Pertemuan kolom & baris → D7 = kolom D baris 7
RangeKumpulan sel berurutan → A1:A5 (A1 sampai A5)
Formula BarKotak di atas grid, tempat menulis rumus
RibbonDeretan menu (Home, Insert, Data, …)

Cara menulis rumus

  • Selalu diawali tanda sama dengan =
  • Ketik di sel atau di Formula Bar, akhiri dengan Enter
  • Nama fungsi tidak case-sensitive: =sum(...) sama dengan =SUM(...)
=5+3 → 8
=B2*2 → isi sel B2 dikali 2
=SUM(A1:A5) → jumlahkan sel A1 sampai A5

Tipe data & perilaku otomatis

  • Angka otomatis rata kanan — bisa dihitung rumus.
  • Teks otomatis rata kiri — tidak ikut perhitungan.
  • Angka yang tersimpan sebagai teks (ada segitiga hijau di pojok sel) bikin SUM hasilnya 0. Hati-hati!

Kesalahan klasik pemula

❌ Lupa tanda = di depan rumus → dianggap teks biasa.
❌ Salah ketik nama fungsi → muncul error #NAME?
❌ Tanda kutip teks kurang → #VALUE!
💡 Excel Indonesia memakai titik koma ( ; ) sebagai pemisah argumen, Excel English memakai koma ( , ). Cek pengaturan region-mu. (Di simulator ExcelLab, keduanya bisa dipakai.)

Referensi absolut: tanda $

Saat rumus di-copy, referensi biasa ikut bergeser (relatif). Kunci dengan $ agar tetap (absolut).

Cocok untuk kurs, harga satuan, atau konstanta lain.
⚡ Tekan F4 saat kursor di referensi untuk berganti mode: A1 → $A$1 → A$1 → $A1

Fungsi Teks

Membedah, menggabung, dan merapikan teks — senjata utama membersihkan data mentah.

Kumpulan fungsi teks

FungsiKegunaanContohHasil
LEFTAmbil n karakter dari kiri=LEFT("MEDAN",3)MED
RIGHTAmbil n karakter dari kanan=RIGHT("EXCEL",2)EL
MIDAmbil dari posisi ke-x sebanyak n=MID("TEKNIK",2,3)EKN
LENJumlah karakter (spasi dihitung)=LEN("HALO")4
UPPER/LOWERKapital / kecil semua=UPPER("medan")MEDAN
PROPERKapital tiap awal kata=PROPER("beryl sinaga")Beryl Sinaga
TRIMBuang spasi berlebih=TRIM(" a b ")a b
CONCATENATEGabung teks=CONCATENATE("A","B")AB
⚡ Operator & lebih cepat dari CONCATENATE: =A1&" "&B1 menggabung dengan spasi di tengah.

Studi kasus: bongkar kode barang

Kode ELT-2024-007 di sel A2 berarti: kategori ELT, tahun 2024, nomor 007.

=LEFT(A2,3) → ELT
=MID(A2,5,4) → 2024 (mulai karakter ke-5, ambil 4)
=RIGHT(A2,3) → 007
=LEN(A2) → 12

Fungsi Logika

Biar spreadsheet-mu bisa "mengambil keputusan" sendiri.

Anatomi IF

=IF(kondisi, nilai_jika_BENAR, nilai_jika_SALAH)
Contoh: =IF(B2>=75,"LULUS","REMED")
  • Teks wajib diapit tanda kutip ganda: "LULUS"
  • Kondisi memakai operator perbandingan:
OperatorArtiOperatorArti
=Sama dengan>Lebih besar
<>Tidak sama dengan<Lebih kecil
>=Lebih besar / sama<=Lebih kecil / sama

AND, OR, NOT

FungsiHasil TRUE jika…Contoh
ANDSemua syarat benar=AND(A2>=75,B2>=75)
ORMinimal satu syarat benar=OR(A2="A",A2="B")
NOTKebalikannya=NOT(A2="GAGAL")
=IF(AND(B2>=70,C2>=70),"LULUS","REMED") → dua-duanya harus ≥70

IF bertingkat (nested IF)

=IF(B2>=85,"A",IF(B2>=75,"B",IF(B2>=60,"C","D")))
💡 Mulai dari syarat paling ketat ke paling longgar (85 → 75 → 60). Kalau dibalik, semua nilai ≥60 langsung tertangkap "C" dan A/B tidak pernah muncul.

Excel baru punya IFS yang lebih rapi untuk kasus bertingkat banyak: =IFS(B2>=85,"A",B2>=75,"B",B2>=60,"C",TRUE,"D")

VLOOKUP & Keluarga Lookup

Mencari data antar tabel otomatis. Ini fungsi yang paling sering ditanyakan saat tes kerja.

Anatomi VLOOKUP

=VLOOKUP(nilai_dicari, tabel_referensi, nomor_kolom_hasil, FALSE)
Contoh: =VLOOKUP(F1, A2:C4, 3, FALSE)
  • nilai_dicari — sel berisi kunci pencarian (mis. kode barang).
  • tabel_referensi — range tabel; kunci WAJIB di kolom paling kiri range.
  • nomor_kolom_hasil — urutan kolom hasil dihitung dari kiri range (kolom 1 = kolom kunci).
  • FALSE — exact match. Hampir selalu pakai FALSE/0.
⚠️ Kesalahan #1: kunci tidak di kolom pertama range → hasil salah/nyasar. Untuk kasus fleksibel, pakai INDEX-MATCH atau XLOOKUP.

Error #N/A dan penangkalnya

=IFERROR(VLOOKUP(F1,A2:C4,3,FALSE),"tidak ketemu")
→ jika data tak ditemukan, tampil teks pengganti, bukan #N/A

HLOOKUP, INDEX-MATCH, XLOOKUP

FungsiKapan dipakai
HLOOKUPSama seperti VLOOKUP tapi tabelnya horizontal (kunci di baris atas)
INDEX+MATCHKunci boleh di mana saja, tahan terhadap sisip/hapus kolom:
=INDEX(C2:C10,MATCH("K02",A2:A10,0))
XLOOKUPExcel 2021/365 — pengganti modern semua di atas:
=XLOOKUP(F1,A2:A4,C2:C4)

Analisis Data & Pivot Table

Dari tumpukan ribuan baris menjadi ringkasan yang bisa "berbicara".

Prinsip data rapi (tidy data)

  • Satu baris = satu record; satu kolom = satu variabel.
  • Baris pertama = judul kolom. Tanpa sel gabungan (merge).
  • Data rapi → Sort, Filter, dan Pivot Table langsung jalan tanpa drama.

Sort & Filter

  • Sort A→Z = ascending, Z→A = descending. Bisa multi-level (urutkan kota, lalu tanggal).
  • Filter: Ctrl+Shift+L — tampilkan hanya baris yang memenuhi syarat.
  • Freeze Panes (View → Freeze Panes): kunci baris judul saat scroll data panjang.

COUNTIF & SUMIF

=COUNTIF(B2:B100,"LULUS") → banyaknya sel "LULUS"
=COUNTIF(C2:C50,">=75") → banyaknya nilai ≥ 75
=SUMIF(A2:A50,"Medan",D2:D50) → total kolom D hanya utk baris "Medan"

Pivot Table dalam 30 detik

  1. Klik di tabel datamu → Insert → PivotTable.
  2. Tarik field ke 4 zona: Rows (pengelompokan), Values (yang dihitung), Columns, Filters.
  3. Klik kanan value → Summarize by → ganti SUM/COUNT/AVERAGE sesukamu.
Contoh nyata: 10.000 baris transaksi → pivot "Total penjualan per kategori per bulan" dalam 3 klik.
